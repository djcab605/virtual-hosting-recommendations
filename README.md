# 虚拟主机推荐：免备案搭 WordPress，个人站长按预算挑机房和面板

搜"虚拟主机推荐"的人通常不是想读一篇行业观察，而是手上真有一个网站要上线：博客、作品站、企业展示页，或者帮人做的 WordPress。真正卡住你的往往是几个很具体的问题——域名要不要备案、机房放香港还是放国内、买宝塔主机还是 EP 主机、一个月二三十块的机器到底能不能跑起来。

这篇就把这几个问题拆开讲，用雨云（RainYun）的虚拟主机做例子，因为它在低价建站这块的套餐结构比较典型：同一款产品分出两种面板、三个机房，价格档位从免费到四十多元一个月，正好覆盖了上面所有选择题。价格和限制都尽量写具体，你看完能直接判断哪一档适合自己。

## 先确认：你要的是虚拟主机，还是云服务器

这两个东西经常被混着叫，但它们解决的场景不一样。

虚拟主机是把环境搭好、面板给你、你只管传网站程序。共享 IP，端口固定，不能改系统，也不能拿来跑游戏服或者做内网穿透。好处是便宜、上手快、不用管运维。

云服务器是你拿到一台独立 IP 的机器，想装什么装什么。代价是价格高一个档，环境要自己配。

判断标准很简单：**你只需要放 PHP 或静态网站，那虚拟主机就够了；你要独立 IP 对外提供服务、要跑 Java 或 Python 后台、要开任意端口，直接看云服务器。**

雨云这边把虚拟主机叫 RVH（Rain Virtual Host），官方定位是"用于快速搭建网站服务的轻量级主机"，所有虚拟主机共用一套自研管理系统，建站、备份、防火墙这些都在一个面板里操作。

## 选虚拟主机绕不开的三个决定

### 1. 机房：其实就是"要不要备案"

这是最容易被忽略、又最影响后续麻烦程度的一项。

- **江苏宿迁**：国内机房，国内访问延迟低，但用它做网站，域名必须先完成备案。没备案的域名解析过去也访问不了。
- **中国香港二区**：免备案，三网直连，延迟在海外机房里算比较低，带宽相对小一些。适合面向国内用户、又不想走备案流程的小站。
- **美国洛杉矶一区**：免备案，国际带宽大，延迟偏高。适合下载站、资源站这类对带宽敏感、对延迟不敏感的业务。

一句话版本：**图省事又不想备案，选香港；要国内速度和防御，选宿迁并准备备案；要便宜大带宽，选洛杉矶。**

### 2. 面板：宝塔和 EP 的区别比价格差更重要

雨云虚拟主机提供两种面板，这个选择实际决定了你后面能干多少事。

**宝塔面板主机**是独享环境，相当于给你一台能用宝塔管理的容器：

- 完全 ROOT 权限，不限网站数量、不限数据库和域名
- 支持 SSH / SFTP / MySQL 远程连接
- 可以装 PHP、Java、Python 等各种环境
- 支持加购独立 IP
- 预装 LNMP，支持自动备份

**EP 面板主机**（EasyPanel，底层是 Kangle）走的是极简路线：

- 只支持 PHP + MySQL 建站，跑不了 Java 类的程序
- 单个主机只能绑 5 个域名，只有一个数据库，环境是 PHP 7
- 操作界面简单，资源占用低

> 如果你不确定选哪个，选宝塔。EP 主机的优势是便宜和轻，但它把"以后可能想折腾一下"的空间也一起砍掉了。价格档位比宝塔主机低一截，具体配置和单价以购买页实时展示为准。

### 3. 配置：别一上来就买高配

虚拟主机最常见的浪费是买太大。一个日均几百访问量的 WordPress 博客，1 核 1G 内存跑起来是没问题的；真正吃资源的通常是插件和没做缓存的图片站，而不是主机本身。

反过来，如果你打算在一个主机上挂三四个站，或者跑 WooCommerce，那 1G 内存会很快见底，直接上 2G 更省事。

## 新手最容易踩的几个坑

这部分是教程里很少集中讲、但基本人人都会遇到一次的问题。

**域名要在两边都绑一次。** 宝塔面板里创建网站并绑定域名之后，还要回到雨云虚拟主机管理面板再绑定一次域名，否则访问不进来。

**程序里的数据库地址写 127.0.0.1，端口 3306。** 雨云面板上显示的那个 MySQL 端口是给远程连接用的。装 WordPress 的时候如果照着面板上的端口填，会连不上数据库。

**远程管理数据库要先放行端口。** 用 Navicat 这类工具连远程 MySQL，需要在宝塔安全设置里开放 3306，并把面板提示的远程端口一起填进去。

**没有独立 IP 时，phpMyAdmin 的访问端口要改。** 把链接里的默认端口 888 换成雨云面板显示给你的端口，不然打不开。

**不要在宝塔里乱改端口和域名。** 改错了面板会连不上，好在雨云提供了修复主机功能，可以自己点一下恢复。

**共享 IP 决定了远程 SSH / SFTP 只适合文件管理。** 想跑别的用途，得加购独立 IP。按第三方测评记录，附加独立 IP 的费用大约是每月 4.68 元，与主机同周期，实际价格看下单页。

## 什么情况下别选虚拟主机

说点反向建议。

如果你需要独立 IP 对外服务、要跑非 PHP 的程序、要自定义端口、要绑十个以上域名做站群，虚拟主机都会让你难受。这种需求应该直接看云服务器，雨云自己也是这么引导的。

另外，如果你的网站已经有稳定流量，或者对可用性有明确的业务要求（比如企业官网挂着订单入口），省下来的那几十块钱不值得你去赌一台共享 IP 主机的稳定性。虚拟主机的定位就是低门槛起步，它在预算有限的时候很好用，仅此而已。

## 常见问题

**虚拟主机能不能跑 WordPress？**
能。宝塔面板主机预装 LNMP，支持一键部署 WordPress，也可以手动上传程序安装。EP 主机同样支持 PHP + MySQL 建站，但只给一个数据库。

**免备案的机房有哪些？**
香港二区和美国洛杉矶一区都免备案。江苏宿迁在国内，做网站需要域名先备案。

**买了之后想换机房怎么办？**
雨云支持按天补差价升级套餐、扩容云盘、迁移地区等操作，虚拟主机也支持一分钟内升级套餐。具体能不能跨机房迁移，建议在工单里确认一次再操作，别自己硬试。

**免费版值得先试吗？**
值得。0 元档的存在让你能在花任何钱之前先摸清后台长什么样、域名怎么绑、备份在哪里设置。摸熟了再决定买哪一档，比直接冲高配更稳。
